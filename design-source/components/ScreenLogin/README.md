Login (`/login`) offers local sign-in with an e-mail address or a name plus password and, when configured, "Inloggen met Authentik" (OIDC). After a first sign-in with a temporary password the user must choose a password before anything else is reachable.

**Anatomy.** **Card:** `pp-auth` (centred, max 380px, `surface`, `border`, `radius-lg`, `space-4` padding and gap) on `bg`: studio name or logo, heading "Inloggen" (`heading-2xl`), FormFields "E-mailadres of naam" (`type="text"`, `autocomplete="username"`; the backend stores a lower-cased login name that may be an e-mail address or a name) and Wachtwoord (`autocomplete="current-password"`), primary button "Inloggen" (full width), the divider `.or` ("of") and the secondary button "Inloggen met Authentik". Only the methods that are configured are rendered: with OIDC only, the form and divider are replaced by the Authentik button; with local only, the divider and the Authentik button are omitted. **Errors:** wrong credentials show an `unpaid` alert under the heading and keep the typed name; a failed Authentik sign-in (the provider sends the browser back to `/login`) shows an `unpaid` alert "Inloggen met Authentik is mislukt. Probeer het opnieuw." above the buttons; HTTP 429 shows a `warning` alert with a clock icon and disables the submit button until the minute has passed; an ended session (60 minutes without activity or 12 hours after signing in) shows an `info` alert "Je sessie is verlopen. Log opnieuw in." **Nieuw wachtwoord kiezen** (shown after signing in with a temporary password, no sidebar or navigation): same card with heading "Nieuw wachtwoord kiezen", the sentence "Je gebruikt een tijdelijk wachtwoord. Kies een eigen wachtwoord om verder te gaan.", FormFields "Nieuw wachtwoord" (help "Minstens 12 tekens en anders dan je tijdelijke wachtwoord.", 2.0) and "Herhaal wachtwoord" (both `autocomplete="new-password"`), primary "Opslaan" and ghost "Uitloggen". Errors are field errors: "Kies een wachtwoord van minstens 12 tekens." and "De wachtwoorden zijn niet gelijk." Authentik users never see this card. On phones (480px and below) `pp-center` pads the page with `space-4` (16px) instead of `space-6`, so the card is full width with 16px margins, and controls are 44px.

**Tokens.** `bg`, `surface`, `border`, `radius-lg`, `space-4`, `heading-2xl`, Button, FormField, Alert tokens. Classes: `pp-auth`, `pp-auth .or`.

**States.** Default, submitting (spinner), wrong credentials, too many attempts, Authentik failed (with and without the local form), session ended, Authentik redirecting ("Doorsturen naar Authentik…"), new password (default, too short, not equal, saving).

**Accessibility.** Autofocus the first field; errors use `role="alert"` (the session notice `role="status"`); field errors are linked with `aria-describedby`; Enter submits.

**2.0.** (2026-10-08) **Choosing the same password again (GAP-100, resolved; official copy).** The backend refuses a new password that equals the current one (`password_unchanged`) and the page mapped only `password_too_short`, so a correct refusal arrived as "Er ging iets mis." The copy, which replaces the placeholder marked `ds-gap: GAP-100`:

- Field error on "Nieuw wachtwoord": **"Dit is je huidige wachtwoord. Kies een ander wachtwoord."** (key `auth.pw.unchanged`), `aria-describedby` on the field, focus moves to it, the typed value is kept.
- The field's help line, which prevents the error rather than reporting it: **"Minstens 12 tekens en anders dan je tijdelijke wachtwoord."** (key `auth.pw.help`), replacing "Minstens 12 tekens."
- The same error applies in ScreenUsers' "Wachtwoord resetten" dialog when an Admin types the user's current temporary password again.

**Rule (new, this is the general lesson).** **Every error code an endpoint can return has a copy key**, and a screen's spec lists the set for each field. "Er ging iets mis." is the fallback for an *unknown* code only, never for a known one; a known code arriving as the fallback is a bug in the mapping, not in the backend. For this field the set is: `password_too_short` → "Kies een wachtwoord van minstens 12 tekens.", `password_unchanged` → `auth.pw.unchanged`, mismatch (client-side) → "De wachtwoorden zijn niet gelijk."

**States (added).** New password: same password as the current one.
