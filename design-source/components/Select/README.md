Select chooses one option from a short list, such as a customer or a role.

**Anatomy.** A styled native `<select class="pp-input pp-select">` with a chevron icon; use the native element so mobile keyboards and screen readers work. For lists that need search (spools) use SpoolPicker.

**Tokens.** Same as TextInput.

**States.** Default, hover, focus, error, disabled.

**Accessibility.** Native semantics; first option may be a placeholder with `value=""`.

**Dutch copy.** Alle klanten, Kies een klant, Rol: Admin, Editor, User.
