Radio picks exactly one of two to five visible options, such as the thema or the invoice type.

**Anatomy.** 20px circle, dot in `primary` when selected; options stacked inside a `<fieldset>` with a `<legend>`.

**Tokens.** `surface`, `border-strong`, `primary`, `focus-ring`.

**States.** Unselected, selected, hover, focus-visible, disabled.

**Accessibility.** `<fieldset>`/`<legend>` group; arrow keys move selection; `Tab` leaves the group.

**Dutch copy.** Thema: Systeem, Licht, Donker.
