Print detail (`/prints/:id`) shows one print: identity and status, the 3D model, its files, the cost breakdown and the payment panel.

**Anatomy.** **Header:** breadcrumb "klant / project", name as `<h1>`, the payment or billing badge, tags, and a danger button "Verwijderen" (ConfirmDialog; deleting hides the print but keeps its financials). **Desktop (901px and up):** two columns, left Viewer3D then the file list (AssetListItem with slots, plates, times printed, duplicates), right "Spoel voor de hele print" (SpoolPicker), CostBreakdown and PaymentPanel. **Phone:** one column in the order Viewer3D (above the fold, fixed aspect ratio), payment, files, costs. **Variants:** *Gearchiveerd* (info alert; files gone from disk, model and downloads unavailable, price and payment stay editable); *Verwijderd* (admin only, unpaid-tinted alert with Herstellen); *Kosten ontbreken* (warning alert with Aanpassen; the suggestion button is disabled); *Vergrendeld* (badge "Op factuur {nummer}" and an info alert; price field disabled); *Niet factureren* (cost shown as "Kosten", PaymentPanel replaced by its note); *Rol User* (name, price and status only; no cost, breakdown, notes or file controls).

**Tokens.** `bg`, `surface`, `border`, CostBreakdown, PaymentPanel, AssetListItem, Viewer3D tokens.

**States.** Loading (Skeleton), default, archived, deleted, missing cost, locked, niet factureren, user role, saving, error.

**Accessibility.** One `<h1>`; each card has a heading; admin-only controls are not rendered for other roles; destructive actions confirm.

**Dutch copy.** Bestanden | Spoel voor de hele print | Bestanden en slots met een eigen spoel gaan hierboven voor. | Gearchiveerd. | Verwijderd op {datum}. | Kosten ontbreken. | Op factuur {nummer}. | Je ziet alleen prijs en status.

**Orders (1.4).** Below the viewer the page lists the orders as OrderSection blocks, newest first ("Nabestelling 2 · 6 okt 2026", "Bestelling 1"); settled orders are closed. Each order has its own files with "Aantal keer geprint", CostBreakdown and PaymentPanel, so a print with one order looks like before (one open section). Files that are in no order appear in an `info` alert "{n} nieuw bestand(en) staan in geen bestelling. Voeg het toe aan een nabestelling." with the button "Nabestelling maken", which opens NabestellingDialog; the same button sits below the list. Deleting the print ("Verwijderen") still hides the whole print with all its orders. The role User sees none of this: name, price, status, thumbnail, 3D model and tags only; the price is the sum over all orders.

**Placement (1.5).** Order of the page with orders: header, Viewer3D (full width), the card "Spoel voor de hele print" (`pp-card pp-sec`, full width, with SpoolPicker and the help "Bestanden en slots met een eigen spoel gaan hierboven voor." — the spool belongs to the print, not to one order), the `info` alert for files in no order, the card **"Nog niet in een bestelling"** (AssetListItem rows with the badge "Niet in een bestelling"), then the OrderSections, newest first, and "Nabestelling maken". Files that never count (STL, video, PDF, links) have no order; they are listed in the Bestanden card of Bestelling 1 so they can still be downloaded. The date in an OrderSection header is the order date: the modification time of the newest counted G-code in that order, else the date the order was created; the invoice Datum and the Van / Tot en met filter use the same date.

**1.6.** (2026-10-07) **Locked orders (GAP-048).** "Spoel voor de hele print" leaves orders that are on a final invoice untouched and says so in its result message; see OrderSection. The help line `pay.lockedHelp` is shown once per locked order, not once per control.
