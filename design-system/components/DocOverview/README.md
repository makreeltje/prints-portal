The overview PDF ("Overzicht") is what a customer downloads from the share page: their prints, customer price and status, never internal cost.

**Anatomy.** Same A4 layout, light only, no number. Title "Overzicht", the sub-line is the link label, the meta grid has Klant, Datum and "Geldig tot" (the expiry of the link). Table columns Print · Project · Datum · Gram · Bedrag · Status; prints without a customer price show "Prijs volgt" and "—" and are excluded from the totals. With "Alleen openstaand" only unpaid and partially paid lines appear and the totals follow. Totals: Totaal, Betaald, Openstaand. Footer: the sentence "Dit is een overzicht, geen factuur.", payment instructions and the page number. Costs, margins, notes and file names never appear.

**Tokens.** Light theme tokens only.

**States.** Full overview, only open, multi-page.

**Accessibility.** Tagged PDF with a real table.

**Dutch copy.** Overzicht | Geldig tot | Prijs volgt | Dit is een overzicht, geen factuur.

**1.5.** One line per order, Datum is the order date, Helvetica (Western European characters only). The payment reference on an Overzicht is the klant name.
