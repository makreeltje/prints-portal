OrderSection is one order of a print: "Bestelling 1" or "Nabestelling {n}". A print always has order 1; a Nabestelling is added when a klant wants more of a project or a part broke. An order has its own items, Verkoopprijs, payments, write-off and, from M7, its own invoice line.

**Anatomy.** `<details class="pp-order">` inside `.pp-orders` (a column, newest order first). **Summary** (`summary`, 44px high on phones, whole row is the toggle): `.ttl` with the title and the date, `.sum` with the status badge, the order total (`pp-money`) and, for a partly paid order, `pp-remaining` "Nog € x open"; `.chev` rotates when open. **Body** (`.bd`): on desktop (`pp-detail`, two columns) the left column holds AssetListItem rows with "Aantal keer geprint" for this order (the same file may appear again in a later order) and CostBreakdown, the right column the PaymentPanel; on phones everything stacks. Orders that are settled (Betaald or Afgeschreven) are closed by default (`details` without `open`), unsettled ones open; the newest unsettled order has `.is-open-order` (`primary` border). **Delete:** "Nabestelling verwijderen" (ghost, bottom of the body; Admin and Editor) is shown for a Nabestelling only while it has no payment, no write-off and (from M7) is not on an invoice; otherwise it is disabled with "Staat op factuur {nummer} en kan niet worden verwijderd." or hidden when payments exist. Bestelling 1 has no delete action. Deleting asks ConfirmDialog "Nabestelling {n} verwijderen?"; the files return to "Niet in een bestelling" in the same project folder. **Payment rules inside an order:** a payment is at most the open remainder; "Betaling ongedaan maken" (Admin only) reverses the most recent payment of this order; undone payments stay in the history (see PaymentPanel).

**Tokens.** `surface`, `border`, `primary`, `radius-lg`, `space-3`, `space-4`, `motion-base`, `muted`, status badge tokens.

**States.** Settled and closed, open with open amount, open and deletable, locked by invoice, focus-visible (summary), reduced motion (no chevron animation).

**Accessibility.** `details` and `summary` give the toggle role and keyboard support (Enter, Space); the summary text reads title, date, status, total and remainder; the focus ring is 2px `focus-ring`; the chevron is decorative (`aria-hidden`).
