Gebruikers (`/users`, admin only) manages who can sign in and with which role.

**Anatomy.** Table: Gebruiker (avatar), Rol (Select: Admin, Editor, User; width class `pp-iwrap compact`, 130px), Herkomst badge (Lokaal or Authentik), actions Wachtwoord resetten (local users only) and an icon button Verwijderen (`aria-label`, ConfirmDialog "Gebruiker '{naam}' verwijderen?" with the sentence "Deze gebruiker kan daarna niet meer inloggen."). An Admin can remove users and change roles; the last Admin can never be removed or demoted: the role select and Verwijderen are disabled for that user, with the help "Er moet minstens één Admin blijven." Role changes save immediately. The primary button "Gebruiker maken" opens a dialog: "E-mailadres of naam" (a lower-cased login name that may be an e-mail address or a name), Rol, "Tijdelijk wachtwoord" (help "Minstens 12 tekens. De gebruiker kiest bij de eerste keer inloggen een eigen wachtwoord."); field errors "Deze gebruiker bestaat al." and "Kies een wachtwoord van minstens 12 tekens." **Wachtwoord resetten** (local users only) opens a small Dialog "Wachtwoord resetten voor '{naam}'" with one field "Tijdelijk wachtwoord" (same help text and the same too-short error) and Annuleren / Opslaan; the admin types the temporary password and the user must choose a new one at the next sign-in (see ScreenLogin, "Nieuw wachtwoord kiezen"). Authentik users have no password actions; Admin comes from the Authentik admin group at sign-in. **Phone:** one card per user; the role is changed with the same native Select inside the card (native selects work well on phones, there is no "Rol wijzigen" button), the actions sit underneath.

**Tokens.** Table, Avatar, Badge, Select, Dialog tokens.

**States.** Loading, default, saving role, error toast, last-admin guard, create (default, user exists, password too short), reset password (default, too short), delete confirm.

**Accessibility.** Table headers with scope; destructive actions confirm; icon buttons carry labels.
