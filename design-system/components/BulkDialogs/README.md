BulkDialogs are what the buttons "Spoel toewijzen" and "Prijs instellen" in BulkActionBar open. Both work on the selected prints, report a result per print and never block the prints that can be updated.

**Anatomy.** **Spoel toewijzen aan {n} prints** (Dialog, 440px, bottom sheet on phones): one line of explanation, the SpoolPicker list (search, spool swatch, name, price per kg; the last option "Geen spoel" removes the spool) and the primary "Toewijzen". It sets the spool for the whole print on every selected print; files and slots that have their own spool keep it. **Prijs instellen voor {n} prints:** one radio group: "Dezelfde prijs voor elke print" with a Verkoopprijs NumberInput (every print gets that price, it is not a total that is split), or "Voorstel uit marge per print ({marge}%)", which gives each print its own suggested price; prints without costs are skipped. The price is set on the **newest order** of each print; if that order is already paid or written off, or is locked by an invoice, that print fails with a reason and the others continue. **Result:** the dialog closes and a Toast "{ok} van {totaal} bijgewerkt" appears; when there were failures a `warning` alert (`role="alert"`) stays above the grid, titled "{n} prints niet bijgewerkt", with one `.pp-results` line per print: name and reason. Reasons: "Nabestelling {n} is al betaald.", "Nabestelling {n} is afgeschreven.", "Staat op factuur {nummer}.", "Deze klant wordt niet gefactureerd.", "Kosten ontbreken.", "Geen toegang." While the call runs the button shows a spinner and both buttons are disabled.

**Tokens.** Dialog, SpoolPicker, FormField, NumberInput, Radio, Alert, Toast tokens. Classes `pp-results`, `pp-picker`.

**States.** Default, saving, all ok (toast only), partial (toast and alert), all failed (alert only, no toast), error (inline alert, nothing changed).

**Accessibility.** Dialogs follow Dialog; the alert is `role="alert"` and is moved to by focus after closing; the result list is a real `ul`; the toast is `role="status"`.
