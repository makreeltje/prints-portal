The reminder PDF ("Herinnering") asks a klant politely to pay what is still open; it has no number and no VAT.

**Anatomy.** Same A4 layout as the invoice, light only. The sub-line reads "Openstaande prints", the meta grid has Klant and Datum only, and a short friendly paragraph precedes the table. The table contains only unpaid and partially paid lines with the remaining amount in Bedrag (for a partial line the status reads Deels betaald); the only total is **Totaal openstaand**. Footer: payment instructions with IBAN and reference, and the page number. Tone: informal "je", no threats, includes "Heb je al betaald, dan kun je deze herinnering negeren."

**Tokens.** Light theme tokens only.

**States.** Single page and multi-page.

**Accessibility.** Tagged PDF; the paragraph is real text.
