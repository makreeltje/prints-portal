Avatar shows a user as initials with name and role; it is used in the app shell and in the Gebruikers list.

**Anatomy.** 32px pill with two initials on `primary-tint-strong`, name (600) and role (`muted`). Role badges: Admin, Editor, User; login origin badges: Lokaal, Authentik.

**Tokens.** `primary-tint-strong`, `text-strong`, `muted`, `radius-pill`.

**States.** Default, in a collapsed sidebar (initials only, name in a tooltip).

**Accessibility.** Initials are decorative; the name is real text. Never show an e-mail address as the only identifier on the share page.

**Dutch copy.** Admin, Editor, User, Lokaal, Authentik.
