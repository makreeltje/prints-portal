Instellingen (`/settings`, admin only) holds the few global settings, stacked as sections in one scrolling page.

**Anatomy.** Sections as cards: **Algemeen** (button "Opnieuw indexeren" with a progress bar and, when done, a result alert; Thema radio Systeem, Licht, Donker); **Prijzen** (NumberInput "Standaardmarge" in %; NumberInput "Stroomtarief" in €/kWh with the help "Gebruikt voor de stroomkosten van elke print: kWh × tarief."; the table "Materiaalprijzen" (`pp-mprices`: Materiaal, Prijs per kg, remove icon button per row; "Materiaal toevoegen" adds a row; a material name is unique, error "Dit materiaal staat er al."; the amounts are the estimated price per kg after Spoolman and a manual price) and its own "Opslaan"); **Printers** (one `pp-printer` card per profile: Naam, Vermogen in W, Aliassen and Timelapse-voorvoegsels as removable chips plus a small input, "Printer verwijderen"; "Printer toevoegen" adds an empty card; empty state "Nog geen printers. Zonder printerprofiel zijn stroomkosten niet meegerekend."; a watt value that is not a whole number gives "Vul een aantal watt in, bijvoorbeeld 350."; "Opslaan" saves the section, deleting a printer asks ConfirmDialog "Printer '{naam}' verwijderen?"); **Bedrijfsgegevens** (Naam, IBAN, Adres, optional E-mailadres and Telefoon, optional Logo upload for PNG or SVG that replaces the studio name; there is no BTW, KvK or VAT field); **Klanten** (one Toggle "Niet factureren" per klant; flagged klanten have no sale price, payment, Openstaand or invoice; they may get a Deel-link, which lists their prints only, without amounts, payment status or PDF buttons); **Spoolman** (status card: Verbonden or Niet bereikbaar with the URL, spool count and last sync). **Phone:** one column, two-field rows stack. Each section saves on its own button; toggles save immediately.

**Tokens.** Card, FormField, NumberInput, Toggle, Radio, Alert tokens.

**States.** Reindex idle, running, done, failed; logo empty and set; Spoolman connected and unreachable (warning alert with Opnieuw proberen).

**Accessibility.** Sections are headings; the progress bar (`pp-progress` with `pp-bar`, width from the data property `--v`) has `role="progressbar"` with values; chip remove buttons carry `aria-label="{alias} verwijderen"`; errors are linked with `aria-describedby`; toggles have visible labels.

**Logo (1.5).** Uploading a logo changes the app too: it replaces the studio name in the AppShell (sidebar, phone top bar, drawer), on documents and on the share page; the icon rail keeps the initial. Allowed: PNG or SVG up to 1 MB. The preview box (`pp-logo-box`, 72×40px) shows the stored PNG.

**1.9.** (2026-10-07) **Unsaved changes (GAP-083, resolved; your decision: per section, with a "changed" state).** Each section saves on its own (unchanged).
