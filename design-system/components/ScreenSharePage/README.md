The share page (`/share/:token`) is what a customer sees when opening a Deel-link, usually on a phone from WhatsApp; it is read-only and needs no login.

**Anatomy.** Lighter and more spacious than the operator UI: no sidebar, single centred column (max 560px on desktop, full width on phones), text at `text-md` or larger, `radius-xl` panels. Top: studio name or logo, heading "Overzicht voor {klant}", the link label and the expiry notice. Then the switch "Alleen openstaand", the list of prints (name, project and date, price, status badge, "Nog € x open" for partial payments, "Prijs volgt" when there is no price), a totals card (Totaal, Betaald, Openstaand; prints without price excluded) and the primary button "Download overzicht" (PDF titled "Overzicht"; with the switch on it contains only open lines). Never shown: internal cost, margin, notes, file names or other klanten. **Link without expiry (Nooit):** the expiry notice is left out. **Not-billed variant** (klant flagged Niet factureren): same head, no "Alleen openstaand" switch, no totals card, no payment badges, no amounts, no PDF button, no footnote; below the heading an intro line "Hier zie je de prints die voor je gemaakt zijn." and only the fields Print, Project and Datum, as a real table on desktop and as a list on phones; the backend returns no prices for these links. **Expired or revoked:** friendly page "Deze link is verlopen of ingetrokken" with a link icon and one explanatory sentence; no navigation. Dark theme follows the visitor's system setting.

**Tokens.** `bg`, `surface`, `border`, `text-md`, `radius-xl`, badge tokens, Button (48px primary).

**States.** Default, only open, empty ("Er staat niets open."), expired or revoked, loading.

**Accessibility.** One `<h1>`; list semantics for the prints; status in text plus icon; the switch has a visible label.

**Dutch copy.** Overzicht voor {klant} | Deze link verloopt over {dagen} dagen ({datum}) | Alleen openstaand | Prijs volgt | Totaal | Betaald | Openstaand | Download overzicht | Prijzen in euro. Prints zonder prijs staan niet in de totalen. | Er staat niets open. | Deze link is verlopen of ingetrokken | Vraag degene die je de link stuurde om een nieuwe. | Hier zie je de prints die voor je gemaakt zijn.

**Inline values (1.5).** The share page uses only classes: `pp-share-line`, `pp-share-amt`, `pp-share-card`, `pp-share-body`, `pp-share-col`, `pp-share-cta`, `pp-illus-box`, `pp-share-h404` plus the helpers `pp-text-sm`, `pp-text-md`, `pp-center-t`, `pp-p4`, `pp-r-xl`, `pp-m0` and `pp-maxch`. Billed and niet-factureren variants share these classes.
