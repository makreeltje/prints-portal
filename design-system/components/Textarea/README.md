Textarea collects free text such as print notes and reminder messages.

**Anatomy.** `.pp-input` on a `<textarea>`, minimum 88px high, vertically resizable, optional character counter in help text.

**Tokens.** Same as TextInput.

**States.** Default, focus, error, disabled.

**Accessibility.** Label required; counter text uses `aria-live="polite"` only when a limit is reached.

**Dutch copy.** Notitie, "Optioneel: bijvoorbeeld de gewenste kleur."
